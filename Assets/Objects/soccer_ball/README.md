# Soccer ball asset

The MuJoCo collision is a 150 mm sphere defined in `soccer_ball.xml`. Unreal
uses `meshes/soccer_ball.glb` as the visual source; its maximum diameter is
exactly 150 mm and its PBR textures are embedded in the GLB.

The visual is adapted from **Soccer Ball Gold** by lagutaojoe on Sketchfab:

https://sketchfab.com/3d-models/soccer-ball-gold-f8bd5eac1aca47c28391426f25824781

It is used under the Creative Commons Attribution 4.0 International license:

https://creativecommons.org/licenses/by/4.0/

Changes made for this project: the source was resized to 150 mm maximum
diameter and its skinned geometry was flattened to a static GLB for Unreal.
